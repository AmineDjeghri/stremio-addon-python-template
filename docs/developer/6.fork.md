# 6. Fork

Start a new Stremio addon from this repository.

## Rename

| What                           | Where                                                                                        |
|--------------------------------|----------------------------------------------------------------------------------------------|
| distribution name, description | `pyproject.toml`: `[project] name`, `description`                                            |
| package folder                 | `src/stremio_addon_python_template/`, imports, and `[project.scripts]` entry points          |
| console script, addon id       | `[project.scripts]` (`stremio-addon`, also in `Dockerfile`, `run.mk`, `test.mk`); `ADDON_ID` |
| logger name                    | `settings.py`: the `name` used to bind and filter the loguru logger                          |
| Docker image name              | `makefiles/docker.mk`: `CONTAINER_NAME`                                                      |
| documentation                  | `README.md`, `AGENTS.md` (`CLAUDE.md` links to it), `properdocs.yml`, `SECURITY.md`, `docs/` |
| version and changelog          | semantic-release owns `project.version` and `CHANGELOG.md`; never edit them by hand          |

Then: `uv lock`, `make install-dev`, `make check`.

## Once on GitHub

1. Create `main` and `dev`, and protect them; use squash merges for pull requests. Allow
   release automation and the documented `main` → `dev` merge sync to push as needed.
2. Workflow permissions "Read and write", and GitHub Pages from `gh-pages`
   ([5. Release](5.release.md#before-you-start)).
3. Install the Renovate app on the repository.

## Stay in sync with upstream

Shared files: `makefiles/`, `Makefile`, `scripts/emoji_commit_parser.py`, `.pre-commit-config.yaml`,
`.markdownlint-cli2.yaml`, `.github/`, `docs/developer/`. This template takes them from the
[Python Package Template](https://github.com/AmineDjeghri/python-package-template); an addon made
from this template takes them from here. Keep the addon-specific edits in `makefiles/run.mk`,
`makefiles/docker.mk` and `makefiles/test.mk` (`stremio-addon` entry point) when syncing.

```bash
git remote add upstream https://github.com/AmineDjeghri/stremio-addon-python-template.git
git fetch upstream
git checkout upstream/main -- makefiles/release.mk   # the files you want
git diff --staged                                     # review before committing
```
